# Staff Workflow Features

- Role login: Owner, Admin, Staff/Cleaner, Client, Affiliate
- Owner dashboard: add homes, edit schedule, assign cleaners, set pay, track paid status
- Admin dashboard: assign staff, update payment status, support owner
- Staff dashboard: assigned homes, pay visibility, clock in/out, checklist, comments
- Client dashboard: book cleaning, price estimate, notes, affiliate discount, reviews
- Affiliate dashboard: referral codes, discounts, commissions
- Monthly schedule: homes by date/time, assigned cleaner/team, staff pay, payment status
- Apps Script tabs included for live Google Sheets backend
