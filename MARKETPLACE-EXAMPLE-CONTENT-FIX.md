# Marketplace example content fix

The marketplace detail pages now contain static photo-based sample content directly in each feature page.

Updated pages:
- Service Storefront (`services.html`)
- Products (`products.html`)
- Locked Content (`locked-content.html`)
- Ads (`ads.html`)
- Boost Service (`boost-service.html`)
- Boost Post (`boost-post.html`)
- Service Gallery (`gallery.html`)

All sample images are bundled locally under `/assets`, so the examples do not depend on Unsplash, an API, login state, saved records, or an internet image request. The sample cards are visible immediately when each feature page opens.
